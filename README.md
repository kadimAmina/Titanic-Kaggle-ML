# Titanic - Machine Learning from Disaster (Kaggle)

## Description

This project is part of the Kaggle competition **Titanic – Machine Learning from Disaster**.
The objective is to predict whether a passenger survived or not based on several features.

## Steps

- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature engineering
- Model training
- Model evaluation
- Kaggle submission

## Result

Final Kaggle accuracy: **0.777**

## Tools

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn
